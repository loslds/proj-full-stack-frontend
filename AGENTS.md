# Instruções do projeto

## Documentação

- Grave a documentação do projeto em `./docs`.
- Use um arquivo Markdown para cada assunto.
- Use nomes de arquivo claros e em minúsculas.
- Crie subpastas dentro de `./docs` quando o assunto for grande.
- Leia `./docs/principios-e-regras-de-ouro.md` antes de alterar o projeto.
- Leia os arquivos de `./docs` antes de alterar o código que eles descrevem.
- Verifique `./docs` quando precisar de contexto do projeto.
- Atualize o arquivo relacionado quando o código mudar.
- Não grave documentação fora de `./docs`.
